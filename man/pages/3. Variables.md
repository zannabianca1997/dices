`dices` support variables to store data and functions for later use. Use the
`let` statement to create a new variable.

```
>>> let x = 3;
>>> x
3
```

Once created, a variable can be modified with the `=` operator.

```
#>> let x = 3;
>>> x
3
>>> x = true;
>>> x
true
```

Variables can be `let`ted multiple times.

```
>>> let x = 3
>>> let x = true
```

## Scoping

With the brackets `{..}` one can create a scope. It can contains multiple
statements, separated by `;`. If the last one is an expression, the scope will
return its value.

```
>>> { 3; 4 + 5; 7 * 2}
14
```

Variables created in the scope do not escape it, and shadows the one at the
outside with the same name:

```
>>> let x = 2 // out of the scope x is 2
>>> {
...   let x = 3; // this x shadows the external one
...   x          // return the value of x inside the scope
... }
3   
>>> x // x outside is unchanged
2
```

If instead the variable is not defined, but written to, it will modify the value
outside:

```
>>> let x = 2 // out of the scope x is 2
>>> {
...   x = 3; // this sets the x variable
...   x      // this x is the one outside!
... }
3   
>>> x // x outside is changed
3
```
