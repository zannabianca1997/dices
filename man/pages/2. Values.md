`dices` support seven types of values: _2.1. Nulls_, _2.2. Bools_, _2.3. Ints_,
_2.4. Strings_, _2.5. Lists_, _2.6. Maps_, _2.7. Closures_, and _2.8.
Intrisics_.

As a dynamically-typed language, all variables in `dices` can be of any type.
Conversion is liberally applied when the wrong type is encountered.

```
>>> 5 + null
5
>>> 23 + true
24
>>> "Hello" ~ [3]
"Hello [3]"
```

This is mainly done in the spirit of `dices` being a language targeted to *table
top gaming*, and so to avoid bogging down the language with programming
concepts. If you are writing something in **`dices`** complex enough for this to
be a problem, please don't.
