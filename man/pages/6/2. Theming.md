Themes are stored as CSS file. All the output of `dices` is organized in virtual
element you can select. If you ever styled a web page, you already know how to
write one.

Said that it actually parse a small subset of the CSS language, but more than
enough for our needs.

## Picking a theme

The active theme is the `theme` key under `[skin]` in your configuration (see
_6.1. Config_):

```toml
[skin]
theme = "CatppuccinMocha"
```

If you do not choose one, `dices` picks a sensible default by looking at how
many colors your terminal advertises: `CatppuccinMocha` when it supports more
than 256 colors, `LowColor` otherwise.

## Bundled themes

Three themes ship with `dices`:

- **`CatppuccinMocha`**: a warm dark palette, the default on truecolor
  terminals.
- **`CatppuccinLatte`**: the light counterpart, for daytime sessions.
- **`LowColor`**: an 8-color adaptation of Mocha, restricted to the standard
  ANSI colors so it renders faithfully on terminals without 256-color or
  truecolor support.

## Custom themes

To add your own, drop a `.css` file into the `themes/` directory of your project
config folder. The file name (without extension) is the theme name. For example,
`~/.config/dices/themes/Sunset.css` becomes the theme `Sunset`, usable with
`theme = "Sunset"`.

If your file has the same name as a bundled theme, the two are layered: the
bundled one is loaded first, then yours is parsed on top. Between two rules with
the same specificity and same `!important`-ness the custom one will win.

This is so it is easy to tweak a bundled theme without copying the whole file:
```css
/* ~/.config/dices/themes/CatppuccinMocha.css */
/* Just change the prompt color */
dices-prompt { color: #f38ba8; }
dices-prompt-indicator { color: #f38ba8; }
```

## What you can style

Every piece of output is tagged with an element name, which you use as a CSS tag
selector. The names mirror the structure of `dices`' output.

Elements have a parent-child relationship that the CSS follows with the usual
cascading rules. All the properties are inherited.

### Values

Covering the printed representation of `dices` values:
- **`dices-value`**: any value, parent of all the ones below. Set styles here to
  affect every kind of value.
- **`dices-value-null`**: the `null` literal.
- **`dices-value-bool`**: `true` and `false`. It carries the attribute
  `[value='true']` or `[value='false']` if you want to style them separately.
- **`dices-value-integer`**: an integer.
- **`dices-value-string`**: a string. To recolor the escape sequences select for
  this element but with the `[escape='true']` attribute.
- **`dices-value-delimiter`**: the brackets and parentheses of lists and maps.
  Both `kind` (`list` or `map`) and `depth` (nesting level, starting at `0`) are
  available as attributes.
- **`dices-value-punctuator`**: commas and other separators.
- **`dices-value-injected`**: an injected value coming from the host.

For rainbow delimiters the attributes `depth-<N>` are available for any `N`,
repeating the colors each `N` levels.
```css
/* Alternate bracket colors every 4 levels of nesting. */
dices-value-delimiter[depth-4='0'] { color: yellow; }
dices-value-delimiter[depth-4='1'] { color: blue; }
dices-value-delimiter[depth-4='2'] { color: magenta; }
dices-value-delimiter[depth-4='3'] { color: cyan; }
```

### Markdown

Banners and this manual are generated from markdown. Markdown elements are
mapped to the usual HTML ones.

- **`dices-markdown`**: any markdown block, parent of all the ones below.
- **`p`**: a paragraph.
- **`h1`** through **`h6`**: headers, by level.
- **`pre`**: a fenced code block.
- **`code`**: inline code.
- **`strong`**: bold text.
- **`em`**: italic text.
- **`ul`**: an unordered list.
- **`ol`**: an ordered list.
- **`li`**: a list item.
- **`dices-markdown-list-marker`**: the bullet or number before an item.
- **`a`**: links

Lists expose `[element='item']` / `[element='marker']` if you need to single out
one of the two.

#### Code examples

Code examples in the manual are executed and printed in your own skin:

```dices-example
>>> 10d6^10 // This will be printed with your prompt and colors configuration 
_
```

### Prompt

The interactive prompt is made of four independently themeable parts.

- **`dices-prompt`**: the prompt as a whole, parent of the next three.
- **`dices-prompt-indicator`**: the chevron before your input.
- **`dices-prompt-multiline`**: the continuation marker on multiline input.
- **`dices-prompt-right`**: the right-aligned prompt, if present.

### Errors

- **`dices-error`**: any error output, parent of the two below.
- **`dices-error-message`**: the top-level error message.
- **`dices-error-cause`**: the underlying cause, when one is available.

### Miscellanea

- **`dices-fluff`**: graphical fluff that should be skipped on plain output.
- **`dices-ast`**: an AST representation, parent.
- **`dices-ast-ident`**: an identifier in an AST.

More `ast` will come if I decide to print the AST.

## Properties

`dices` understands the following CSS properties and custom ones. Anything else is silently ignored.

- **`color`**: foreground color.
- **`background-color`**: background color.
- **`font-weight`**: only the value `bold` is supported.
- **`font-style`**: only the value `italic` is supported.
- **`text-decoration`**: accepts `underline`, `line-through`, or `none`, or
  combinations.
- **`intense`**: Use the bright ANSI variant on terminals if `true`.
- **`dimmed`**: Dims the text if `true`.
- **`reset`**: Controls whether the terminal output is reset before applying
  this style. On by default.

## Colors

A color value can be written in any of these forms:

- A named color: `black`, `blue`, `green`, `red`, `cyan`, `magenta`, `yellow`,
  `white`.
- A 256-color index: `ansi-N`, where `N` is between `0` and `255`.
- A hex color: `#rrggbb` or `#rgb`.
- `none` or `transparent`, to leave the color unchanged.

The 256 or hex color variants will work only on terminals that supports them.

## A complete theme

Here is an example theme. Saving it as `~/.config/dices/themes/Simple.css` would
make it selectable with `theme = "Simple"`.

```css
/* Simple - an 8-color theme. */

/* Values */
dices-value-null      { color: white; dimmed: true; }
dices-value-integer   { color: yellow; }
dices-value-bool      { color: magenta; }
dices-value-string    { color: green; }
dices-value-string[escape='true'] { color: yellow; }
dices-value-delimiter[depth-4='0'] { color: yellow; }
dices-value-delimiter[depth-4='1'] { color: blue; }
dices-value-delimiter[depth-4='2'] { color: magenta; }
dices-value-delimiter[depth-4='3'] { color: cyan; }
dices-value-punctuator { dimmed: true; }
dices-value-injected  { color: yellow; }

/* Markdown */
h1, h2      { font-weight: bold; }
h1          { color: yellow; }
h2          { color: blue; }
h3          { color: magenta; }
h4          { color: cyan; }
pre, code   { color: magenta; }
strong      { font-weight: bold; }
em          { font-style: italic; }
dices-markdown-list-marker { font-weight: bold; color: green; }

/* Prompt */
dices-prompt           { color: blue; }
dices-prompt-indicator { color: green; }
dices-prompt-multiline { dimmed: true; }
dices-prompt-right     { dimmed: true; }

/* Errors */
dices-error          { color: red; }
dices-error-message  { font-weight: bold; }
```
