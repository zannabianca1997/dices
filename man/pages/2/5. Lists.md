Lists can contain any number of values, of any type. They are inserted with the
`[..]` notation. They are also produced by the repeat `^` operator, and by
throwing multiple dices

```
>>> [1, true, "hello"]
[1, true, "hello"]
>>> 3 ^ 5
[3,3,3,3,3]
>>> 3d6
[1..=6, 1..=6, 1..=6]
```

They can be concatenated with the join `~` operator, that will also add single
values or flatten maps.

```
>>> [1, 2, 3] ~ [4, 5, 6]
[1,2,3,4,5,6]
>>> [true, false] ~ null
[true, false, null]
>>> ["Hello"] ~ <|b: "beautiful", w: "world"|>
["Hello", ["b", "beautiful"], ["w", "world"]]
```

Single elements of the list can be accessed by indexing it with square brackets.
The index is 0-based, meaning that the element `x[0]` is the first one.

```
>>> let x = [3, 2, 1];
>>> x[0]
3
>>> x[1 + 1]
1
```

If the index is negative, the list is instead indexed from the end, with `x[-1]`
being the last element.

```
>>> let x = [1, 2, 3];
>>> x[-1]
3
>>> x[-2]
2
```

Lists can be sliced with a tuple of integers.

```
>>> let x = [1, 2, 3, 4, 5];
>>> x[[1,4]]
[2, 3, 4]
```

Finally, if the index is known and positive, one can index the list with the `.`
notation.

```
>>> let x = [3, 2, 1];
>>> x.0
3
>>> x.2
1
```

If the index is bigger than the list length, it wraps around.

```
>>> let x = [1, 2, 3, 4, 5];
>>> x[5]
1
>>> x[-6]
5
```

Elements of a list can be replaced by assigning to an index. The same wrapping
rules as reading apply.

```
>>> let x = [1, 2, 3];
>>> x[1] = 9
>>> x
[1, 9, 3]
>>> x[-1] = 0
>>> x
[1, 9, 0]
```

A slice of elements can be replaced by assigning a list to a range index. The
replacement list does not need to have the same length as the replaced slice.
If the assigned value is not a list, it is converted to one with the
[to_list][5.5. Convert] conversion.

```
>>> let x = [1, 2, 3, 4, 5];
>>> x[[1, 3]] = [9, 9, 9]
>>> x
[1, 9, 9, 9, 4, 5]
>>> x[[0, 1]] = 0
>>> x
[0, 9, 9, 9, 4, 5]
```

Assigning to an empty range inserts the elements at that position.

```
>>> let x = [1, 2, 3];
>>> x[[1, 1]] = [9]
>>> x
[1, 9, 2, 3]
```

Nested lists can be modified by chaining member accesses.

```
>>> let x = [[1, 2, 3], [4, 5, 6]];
>>> x[0][2] = 99
>>> x
[[1, 2, 99], [4, 5, 6]]
```
