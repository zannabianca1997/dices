Strings are piece of text. They can be represented with the quoted notation

```
>>> "Hello world!"
"Hello world!"
```

Strings are unicode, and one can use escape codes to insert quotes, newline and
other chars

```
>>> "Those are\n two lines"
"Those are\n two lines"
>>> "Hello \"world\""
"Hello \"world\""
```

The accepted escape codes are:

- `\\`: Reverse slash
- `\n`: Newline
- `\r`: Return carriage
- `\t`: Tabulation
- `\0`: Null
- `\"`: Double quote
- `\xHH`: Ascii. Two hexadecimal digit, from 00 to 7F
- `\u{HH..}`: Unicode. Up to 6 hexadecimal digits, must be a valid unicode codepoint

Conversion to and from other values can be made with the [apposite module][5.5.
Convert].

Single characters of the string can be accessed by indexing it with square
brackets. The index is 0-based, meaning that the characters `x[0]` is the first
one.

```
>>> let x = "Hello";
>>> x[0]
"H"
>>> x[1 + 1]
"l"
```

If the index is negative, the string is instead indexed from the end, with
`x[-1]` being the last characters.

```
>>> let x = "Hello";
>>> x[-1]
"o"
>>> x[-2]
"l"
```

A tuple of numbers can be used to slice the string:

```
>>> let x = "Hello";
>>> x[[1,4]]
"ell"
```

Finally, if the index is known and positive, one can index the string with the
`.` notation.

```
>>> let x = "Hello";
>>> x.0
"H"
>>> x.2
"l"
```

If the index is bigger than the string length, it wraps around.

```
>>> let x = "Hello";
>>> x[5]
"H"
>>> x[-6]
"o"
```
