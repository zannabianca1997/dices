Closures are expressions that can be stored for later execution. They can be
used for example to store throws for later.

```
>>> let hit_with_mace = || d20 + 3
>>> hit_with_mace()
4..=23
>>> hit_with_mace()
4..=23
```

The closure can have any number of parameters.

```
>>> let add_multiply = |a,b,c| a * b + c
>>> add_multiply(3, 2, -3)
3
```

Finally, closures can capture values from the environment. The values are
constant, no reference is kept to the original variable.

```
>>> let STR = 3;
>>> let hit_with_mace = || d20 + STR
>>> hit_with_mace()
4..=23
>>> STR = -50;
>>> hit_with_mace()
4..=23
```
