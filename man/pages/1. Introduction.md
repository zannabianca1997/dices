This is the manual for `dices`, a dice-throwing simulator, turned Turing
complete programming language. It supports standard dice notation:

```
>>> d6
1..=6
>>> d20
1..=20
>>> 3d10
[1..=10, 1..=10, 1..=10]
```

That can be combined with the usual arithmetic operations:

```
>>> 3 + 4
7
>>> 3 * 2 - 7
-1
>>> d6 + 10
11..=16
```

And operations related to dices, like filtering for highest-lowest dices:

```
>>> 2d20 kh 1 // throws 2 d20, then keep the highest
[1..=20]
>>> 5d10 kl 2 // throws 5 d10, then keep the 2 lower ones
[1..=10, 1..=10]
>>> 3d8 rh 1 // throws 3 d8, remove the higher one
[1..=8, 1..=8]
>>> 5d4 rl 2 // throws 5 d4, remove the two lower ones
[1..=4, 1..=4, 1..=4]
```

More programming related concept, like variables, scopes and closures, are also
available:

```
>>> let STR_MODIFIER = 3;
>>> STR_MODIFIER
3
>>> STR_MODIFIER = 2;
>>> STR_MODIFIER
2
>>> {
...     let STR_MODIFIER = 4;
...     STR_MODIFIER
... }
4
>>> STR_MODIFIER
2
>>> let str_throw = || d20 + STR_MODIFIER;
>>> str_throw()
3..=23
```

## Where to go from here

This is only the introduction. Type `help([])` for the full index, then
`help([6,2])` for example to see the page _6.2._

The manual is not specifically targeted neither to programmers nor tabletop
gamers, but to the kind of people that use a computer program to play *DnD*. I
tried to make it accessible to people that only want to throw dice, but some
arguments might need more programming knowledge.
