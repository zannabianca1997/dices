# `dices` 0.4.1

This is a program able to simulate dice-throwing. It supports traditional dice
notation, but also mathematical operations, variables, and closures. 

## Installing

For now the only way of installing this program is building it from source.

Ensure [`cargo`](https://doc.rust-lang.org/cargo/) is installed on your computer
and then run:

```sh
cargo install --git https://repos.zannabianca1997.site/zannabianca1997/dices.git
```

You should see a lot of text while it compiles. When it stop, run `dices` and
then a prompt similar to `>>>` should appear. Press `Ctrl + D` to exit.

## Where to go from there

`dices` has an internal manual. Type `help()` in the *REPL* to get started.

The manual is not specifically targeted neither to programmers nor tabletop
gamers, but to the kind of people that use a computer program to play *DnD*. I
tried to make it accessible to people that only want to throw dice, but some
arguments might need more programming knowledge.
